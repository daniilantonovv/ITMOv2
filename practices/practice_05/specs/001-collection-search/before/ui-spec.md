**UI Спецификация: Поиск по подборкам (WkusVill Collections)**

**Состояния интерфейса:**
1.  **Ожидание запроса:** Поле ввода пустое, фокус активен. Загрузка отсутствует.
2.  **Загрузка:** Индикатор активности в поле поиска или сверху.
3.  **Успешная выдача:** Список карточек подборок (показывать заголовки с русскими названиями). Отображать: `null` результаты и код ошибки API (`400`, `500`).
4.  **Загрузка/Ошибка:** Заполненный результат запроса или отображение ошибки. В случае ошибки выдавать соответствующее уведомление.

**Действия:**
1.  Пользователь вводит текст в поле поиска.
2.  Система очищает ввод от лишних пробелов.
3.  UI вызывает GET-запрос на backend при изменении текста или через кнопку "Поиск".

**Предлагаемый контракт API:**
*   **Метод:** `GET`
*   **Путь:** `/api/collections?search=...`
*   **Задачи по поиску:** Поиск по русским названиям подборок и продуктов в подборке.
*   **Структура ответа:**
    *   Список объектов, каждый из которых содержит: `id`, `title`, `category`, `cart_url`, `created_at`.
    *   Количество элементов (`total_count`).
