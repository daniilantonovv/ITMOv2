# Контрольный запуск без примеров

> **Исполнитель — не OpenCode.** Шлюз VseLLM 20.09.2026 не отвечал, поэтому контроль выполнен агентом Claude Opus 5 (Claude Code). Ограничение честно фиксируем: контроль и основной запуск сделаны на разных моделях, а исполнитель контроля уже видел ответ основного запуска, поэтому контроль не «слепой». Для чистого сравнения нужен повтор на `gpt-5` с чистой сессией.

Запрос (тот же, что в основном эксперименте, но без блоков «Хороший результат» и «Плохой результат»):

```text
Задача: переписать acceptance criteria (Gherkin) для фичи "Защита секретов (US-2)" AI-помощника ревьюера PR. Правило SEC-1: перед отправкой во внешний LLM из diff удаляются токены, пароли и приватные ключи.

Сделай 4 сценария для US-2: (1) пароль в строке подключения к БД в URL, (2) приватный ключ PEM из нескольких строк, (3) ложное срабатывание — обычный код со словом token не должен меняться, (4) секрет в удалённой строке diff (начинается с "-"). Только Gherkin, без пояснений.
```

Ответ:

```gherkin
Feature: Удаление секретов из diff перед отправкой в LLM

  Scenario: Пароль в строке подключения к БД
    Given diff содержит строку подключения к базе данных с паролем
    When сервис готовит запрос к внешнему LLM
    Then пароль в строке подключения заменён на маркер редактирования
    And остальная часть URL остаётся читаемой

  Scenario: Приватный ключ из нескольких строк
    Given diff содержит блок приватного ключа в формате PEM
    When сервис готовит запрос к внешнему LLM
    Then содержимое ключа не передаётся во внешний сервис
    And факт наличия ключа в diff сохраняется для ревьюера

  Scenario: Обычный код со словом token не изменяется
    Given diff содержит код, в котором слово token используется как имя переменной
    When сервис готовит запрос к внешнему LLM
    Then этот фрагмент передаётся без изменений

  Scenario: Секрет в удалённой строке
    Given diff содержит удалённую строку с паролем
    When сервис готовит запрос к внешнему LLM
    Then значение пароля не передаётся во внешний сервис
```
