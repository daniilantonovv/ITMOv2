# Журнал экспериментов Практики 2

- Выбранный слабый артефакт Практики 1: [`practice_01/problem.md`](../practice_01/problem.md), раздел «Метрики». У двух метрик базовое значение было допущением, ни у одной не было порога принятия решения. Техники применялись и к связанным файлам, где они полезнее.
- Что в нём нужно улучшить: у каждой метрики должны быть проверяемый источник, совместимый с OBS-1, и порог решения. Связанные артефакты должны покрывать все правила SEC-1…OBS-1 проверками.
- Как поймём, что изменение полезно: у каждой метрики есть источник и порог; у каждого правила есть хотя бы одна проверка (матрица из RAG); ReAct не находит битых ссылок; `make test` зелёный.

Все запуски: OpenCode 1.18.29, `vsellm/openai/gpt-5`, agent `plan`, в отдельной папке только с приложенными файлами. Ответы модели без правок лежат в `result.md` в папке каждой техники.
