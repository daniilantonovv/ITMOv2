**Нет, подписи НЕ сохраняются после перезапуска процесса.**

Код в Python показывает, что:

1. `subscribers = set()` — это глобальная переменная
2. При каждом запуске интерпретатора создается **новая память** с чистым контекстом (включая `subscribers.clear()` в unittest)
3. Глобальные объекты Python создаются при импорте модуля, но если вы запускаете `.py` файл повторно, весь код выполняется заново

В тестах видно подтверждение:
- В `setUp()` вызывается `subscribers.clear()` — значит в новом запуске подписок нет
- При повторном вызове `subscribe("Ann")` добавляет новую запись (строка 7 файла `service.py`)
