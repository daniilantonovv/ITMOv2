## Что помогло

- **Падающий тест как доказательство.** С TDD-skill агент сначала показал
  красные тесты (201/200 вместо 409). Сразу видно, понял ли он требование.
  Без этого оставалось бы верить фразе «готово».
- **Hook вместо обещаний.** После каждой правки `check.sh` запускался сам,
  и FAIL/PASS попадал агенту в ответ инструмента. Агент видел реальные
  результаты, а не свой пересказ.
- **Context7 по делу.** Документация FastAPI по exception handler пришла
  через MCP, и агент применил её в фиче A, когда я попросил убрать
  дублирование.
- **Контракт как источник правды.** Когда в `docs/requirements.md` есть
  точные коды и тексты ошибок, и агенту, и ревью есть с чем сверяться.

## Где агент ошибся и пришлось вмешаться

- **Фича A: гонка.** Агент сделал проверку «SELECT, потом INSERT». Тесты
  зелёные, но два одновременных запроса прошли бы оба. Нашлось только при
  чтении диффа. После замечания он поставил UNIQUE-индекс. Его «тест на
  гонку» прошёл и до исправления, то есть ничего не доказывал.
- **Фича B: слабые тесты и вечный 503.** Все 8 тестов ломали базу до старта
  приложения, а сценарий «база сломалась во время работы» не проверялся.
  Ещё ошибка при старте давала 503 до перезапуска. Исправлено тестами
  восстановления и мутационной проверкой (убрал обработку — упало 9 тестов).
- **Утечка ключа.** Агент запустил `git diff` по всему репозиторию и вывел
  ключ из корневого `opencode.json`, хотя AGENTS.md запрещал читать этот
  файл. Запрет на чтение файла не покрывает команду, которая его покажет.
  Теперь правило и права `tester` разрешают только `git diff -- .`.

## Что мешало

- **Версия OpenCode.** Слайды под 2.0.20, у меня 1.18. Другой формат MCP,
  другой API плагинов, нет `opencode reload`. Hook пришлось писать на
  `tool.execute.after`.
- **Провайдер модели.** `claude-sonnet-4` пропала из VseLLM (404), потом
  закончился бюджет (402). OpenCode показывал оба случая одинаково:
  «Request failed». Причину нашёл только прямой запрос curl. Из-за этого
  ревью B через `@explore` не состоялось, и код ДЗ писал Claude Code.
- **Локальная модель.** qwen3.5:4b отвечала почти 3 минуты на короткий
  ревью-запрос. Для агентной работы непрактично.
